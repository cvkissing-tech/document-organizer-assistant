# 文档整理助手 / Document Organizer

一款面向 Android 11 及以上设备的本地文档整理应用。它聚焦于“找到文档、识别版本、完成归类”，帮助用户处理散落在不同文件夹中的 PDF 与常见 Office 文档。

> **不只比较文件名：应用会综合核心名称、版本标记、文档内容与结构、所在目录、修改时间、文件大小和格式等证据，发现可能属于同一份文档的不同版本，并把判断依据展示给用户。**

文档整理助手不会仅凭相似名称自动删除文件，也不会擅自决定哪个版本应被保留。应用负责缩小查找范围、解释相似原因，最终由用户确认当前版本或排除错误关系。

## 核心能力

| 功能 | 说明 |
| --- | --- |
| 文档扫描 | 扫描全部文档，或只扫描用户授权的指定文件夹 |
| 多证据版本识别 | 综合名称、版本标记、内容、结构、目录、时间、大小和格式，判断文档之间是否可能存在版本关系 |
| 可解释结果 | 区分高可信、待判断和已排除关系，并展示支持证据与冲突依据 |
| 完全重复 | 先按文件大小筛选候选，再通过内容哈希确认完全相同的副本 |
| 版本确认 | 将候选版本放在同组中对比，由用户选择当前版本或排除错误关系 |
| 虚拟分类 | 自定义分类与标签，不移动原文件位置 |
| 文件操作 | 打开、分享、批量归类，并通过 Android 系统确认移入回收站 |
| 双语界面 | 支持简体中文与英语 |

## 核心亮点：多证据文档版本识别

普通的名称匹配容易把“第一章”和“第二章”、不同年份的报告，或者不同人员的同名作业错误地放在一起。本应用采用分阶段识别方式：

```text
扫描并建立文档索引
        ↓
规范化名称，提取核心名称与版本标记
        ↓
识别年份、章节、作业编号、人物等冲突信息
        ↓
生成有数量上限的候选组合
        ↓
提取可解析 Office 文档的正文与结构指纹
        ↓
综合名称、内容、格式、目录、时间与大小
        ↓
输出高可信 / 待判断 / 排除，并交给用户确认
```

| 识别层级 | 作用 |
| --- | --- |
| 名称规范化 | 清理常见副本标记、版本词、符号和噪声，提取相对稳定的核心名称 |
| 保护信息与冲突检测 | 识别年份、章节、作业编号、人物等信息，减少同名但不同内容的误判 |
| 候选规模控制 | 避免对全部文档进行低效的两两比较，并限制单文档与全局候选数量 |
| 正文指纹 | 对可解析的 Word、Excel、PowerPoint 文档提取规范化文本指纹 |
| 结构特征 | 记录段落、表格或工作表、幻灯片、图片和标题等结构信息 |
| 多信号评分 | 综合核心名称、版本标记、目录、修改时间、大小、格式和内容相似度 |
| 可信度分层 | 将关系划分为高可信、普通候选或排除，避免把模糊结果伪装成确定结论 |
| 用户反馈 | 保存用户的确认与排除选择，尊重用户对文档关系的最终判断 |

完全重复识别与版本相似识别是两条独立链路：前者使用内容哈希确认文件是否完全相同；后者判断内容发生修改的文件是否可能属于同一文档的不同版本。

### 当前识别边界

- `docx`、`xlsx`、`pptx` 支持正文与结构特征提取。
- PDF 当前参与核心名称、版本标记、目录、时间、大小和格式等信号判断，暂未提取 PDF 正文用于版本相似验证。
- 加密、损坏或无法解析的 Office 文档会退回到可用的名称与元数据信号，不会被当作已经完成内容验证。
- 工程回归数据用于防止算法修改造成明显退化，不代表真实用户场景中的准确率承诺。

## 产品原则

- 以整理文档为核心，不扩展为复杂的通用文件管理器。
- 版本识别同时展示支持证据和冲突信息，不自动替用户决定最终版本。
- 分类只保存应用内关系，不改变设备上的原始路径。
- 文件扫描和分析在本机完成。

## 运行要求

- Android 11（API 30）或更高版本
- Android Studio 与 JDK 17
- Android SDK 37

## 本地运行

1. 克隆仓库并用 Android Studio 打开根目录。
2. 等待 Gradle 同步完成。
3. 连接 Android 11 及以上真机，运行 `app` 配置。
4. 首次使用时选择“全部文档”或“指定文件夹”扫描方式。

命令行检查：

```bash
./gradlew :app:testDebugUnitTest :app:lintDebug
```

Windows PowerShell：

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug
```

## 权限说明

“全部文档”扫描需要 Android 的所有文件访问权限；“指定文件夹”模式使用系统文件夹选择器，只访问用户明确授权的位置。应用只筛选 PDF、Word、Excel 和 PowerPoint 等支持的文档类型。

## 已知边界

- Office 文档通常交由设备上兼容的外部应用打开。
- 删除流程依赖 Android 11 及以上的系统确认与回收站能力。
- 不同手机厂商的文件提供器行为可能不同，发布前仍需真机验证授权、扫描、分享和删除流程。
