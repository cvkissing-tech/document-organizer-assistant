# 产品与界面设计说明

## 核心任务

用户打开应用后应优先完成三个动作：

1. 扫描并发现文档。
2. 处理名称相似或完全重复的文档组。
3. 将文档放入自定义虚拟分类。

## 信息层级

| 层级 | 内容 |
| --- | --- |
| 一级 | 待确认文档与扫描状态 |
| 二级 | 待归类文档、最近打开 |
| 三级 | 全部文档、分类与设置 |

## 视觉原则

- 主色用于关键操作和当前状态，危险操作单独使用警示色。
- PDF、Word、Excel、PowerPoint 使用稳定且易辨认的类型色。
- 同一页面只保留一个主要按钮，次要操作降低视觉权重。
- 标题、正文、辅助信息保持固定字号层级，避免说明文字堆叠。
- 相似与重复结果必须同时展示判断类型和用户可核对的事实依据。

## 交互原则

- 不根据相似度自动删除文件或自动选择最终版本。
- 批量操作必须显示已选择数量，并在危险操作前再次确认。
- 权限页面同时说明“全部文档”和“指定文件夹”的差别，让用户自主选择。
- 空状态说明下一步操作，不展示虚构的示例文件。
