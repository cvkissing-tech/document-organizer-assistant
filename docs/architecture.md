# 架构说明

## 数据流程

```text
系统存储 / 用户授权文件夹
            │
            ▼
      文档扫描与类型过滤
            │
            ▼
  文件元数据与内容特征提取
        │           │
        ▼           ▼
  名称相似分组   完全重复分组
        └─────┬─────┘
              ▼
       用户确认与虚拟分类
              │
              ▼
      Room / DataStore 本地保存
```

## 主要模块

| 模块 | 职责 |
| --- | --- |
| 扫描层 | 访问 MediaStore 或用户授权目录，筛选支持的文档 |
| 识别层 | 规范化名称、计算相似度，并校验完全重复内容 |
| 数据层 | 保存文件索引、分类、确认状态和设置 |
| 界面层 | 展示首页、文档、分类、确认、设置和异常状态 |
| 系统交互 | 调用外部应用打开/分享文档，调用系统回收站确认 |

分类记录引用文件标识，不改变文件在设备中的实际位置。文件发生移动或删除后，需要重新扫描以更新索引。
